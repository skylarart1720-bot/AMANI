Purpose and intended users.

AMANI is a Ghana-first rights, safety and wellbeing information/referral service. Visitors should reach credible information and routes to accountable human help without registering or supplying identity details.

Service boundaries

AMANI does not guarantee emergency intervention, legal representation, treatment, partnership acceptance or immediate human response. A directory and queue do not establish a staffed service.

Completion has two layers

Launch readiness means all advertised channels are dependable, private, reviewed and staffed. Full blueprint delivery additionally includes Ghanaian languages, scheduled reviewed knowledge, aggregate reports, richer referrals, consented follow-up and later SMS/USSD. Agree these milestones separately.

Witchcraft-accusation work crosses multiple pillars: approved content and actual referrals are needed, not only a topic description.

Architecture and hosting model.

Visitor → public Next.js /api proxy
Moderator → moderator Next.js /api proxy
↓ HTTPS orchestrator origin
FastAPI main.py installs support.py
Sessions · triage · knowledge · referrals · queue · SSE
↙ support.db   ↓ AI provider   ↘ private URL scanner
WhatsApp ↔ Meta ↔ HTTPS gateway /webhook
Encrypted whatsapp.db → single worker → same support API

Single-node baseline

Use one orchestrator instance, one Uvicorn worker and one mounted SQLite volume. Scanner stays internal. Gateway needs persistent storage and one worker. Vercel hosts frontends; its server proxy needs an externally reachable HTTPS API because it cannot access Railway private hostnames.

Realtime and scale

Visitor/moderator SSE checks changes once per second. Clients reconnect and poll as fallback. Validate hosted buffering and duration limits. Do not enable replicas or multiple gateway workers until storage, job coordination and limits are shared.

Privacy

Fernet encrypts stored message content; visitor capability tokens are hashed. The server and authorised staff can read chats. Web chat is not end-to-end encrypted against AMANI. Staff currently share a bearer token via a secure HTTP-only dashboard cookie.
